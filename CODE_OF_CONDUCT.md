# Code of conduct

Be kind and assume good intent. Disagree about the work, never about the person.

Not okay here: harassment, insults, personal attacks, discriminatory language, sharing someone's
private information, or posting investment tips and promotion in issues and pull requests.

If someone's behaviour bothers you, report it to the maintainer privately through GitHub (use the
"Report content" option on the comment or issue, or the private report link in
[SECURITY.md](SECURITY.md) if it's urgent). Reports are kept confidential. The maintainer may edit or
remove comments and block people who don't follow this.
